# Rupshora — Small Acts, Greater Impact

**Live Website:** https://rupshora-khulna.vercel.app

Rupshora is a community service platform that helps people discover volunteering opportunities, participate in events, and contribute to positive social change.

## Features

- User registration and login with authentication.
- Browse upcoming community events and view event details.
- Create, update, and manage community events.
- Join events and view joined events.
- Search events by title, description, location, and organizer.
- Filter events by category.
- Explore community moments through a photo gallery.
- Responsive interface with light and dark themes.
- Protected features for authenticated users.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Express.js
- MongoDB
- Better Auth


## Deployment

The client is deployed on Vercel. Configure the required environment variables before running the application locally or deploying it.
